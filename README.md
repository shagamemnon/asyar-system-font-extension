# System Font

Makes Asyar use your operating system's own font instead of its built-in Satoshi typeface, so the launcher matches the rest of your desktop.

| Platform | Font used |
| --- | --- |
| macOS | San Francisco |
| Windows | Segoe UI Variable / Segoe UI |
| Linux | Your desktop's default sans-serif font |

## What it changes

Only the interface font. Your colors, light/dark mode, spacing and code font (JetBrains Mono) stay as they are, so you can keep the default look and just change the typeface.

## How to use

1. Install **System Font** from the Asyar Store.
2. Open **Settings → Appearance → Custom Themes**.
3. Select **System Font**. It applies immediately, with no restart.

To go back to Satoshi, select **Default** in the same list.

## Notes

- Asyar's letter spacing for large headings is tuned for Satoshi, and themes can't change it, so big titles may look slightly tighter than usual.
- This theme ships no font files. It uses the fonts already installed on your system.
